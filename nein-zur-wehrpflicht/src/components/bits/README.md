# Bausteine aus React Bits

Die Komponenten in diesem Ordner basieren auf [React Bits](https://github.com/DavidHDev/react-bits)
von David Haz (Lizenz: MIT + Commons Clause). Sie wurden für diese Seite angepasst:
deutsche Zahlen, Barrierefreiheit, reduzierte Bewegung und weniger Rechenlast auf Handys.

| Datei | Vorlage in React Bits |
| --- | --- |
| `RollingNumber.tsx` | Components/Counter |
| `VelocityMarquee.tsx` | TextAnimations/ScrollVelocity |
| `CircularBadge.tsx` | TextAnimations/CircularText |
| `FlapText.tsx` | TextAnimations/SplitFlapText |
| `HalftonePhoto.tsx` | Animations/HalftoneReveal |

Commons Clause: Die Bausteine dürfen nicht als eigenes Produkt weiterverkauft werden.
Die Verwendung auf dieser Website ist erlaubt.
