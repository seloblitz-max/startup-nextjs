# Dateien für Teilen-Bilder

Diese Dateien nutzen die Teilen-Bilder (`opengraph-image`, `/story/<stadt>`), sie werden auf dem Server gelesen.

- `fonts/`: Big Shoulders, Bricolage Grotesque, Martian Mono (SIL Open Font License 1.1) und
  Permanent Marker (Apache License 2.0), als WOFF aus den Fontsource-Paketen.
- `og-tor.jpg`, `story-tor.jpg`: Symbolbild Brandenburger Tor, aus dem Bild in `public/img/tor.jpg`.
- `crown.ts`: Kronen-Symbol aus Phosphor Icons (MIT).
